Wealth-Agent / 公開表面の解析

公開されているものだけを読み、入口と根拠を返す

URL を入れると、そのサービスが公開している入口（API の候補・フォーム・フィード・MCP ツール）を、根拠と「分からなかったこと」つきで返す。認証の突破はしない。401/403 は「要認証」と記録して止める。

例:

結果待機中

URL を入れて「解析する」を押すと、ここに結果が出ます。解析はサーバー側で1回だけ取得します。

この道具が守ることやらないこと

  • 読むのは公開されている応答だけ（認証情報を使わない）
  • 401 / 403 は「要認証」と記録して止める。突破はしない
  • robots.txt を尊重し、対象へのアクセスは1回ずつ
  • 再配布・再販はしない（出典URLを必ず残す）

使い方無料と有料

  • 1. 上の欄にURLを入れて解析する無料
  • 2. 要約（入口の候補・痕跡・分からなかったこと）を読む無料
  • 3. 全件＋根拠の全文＋実装メモ0.25 USDC

有料面: POST /api/x402/surface-report（x402）／ MCP ツール buy_surface_report／ 無料面: GET /api/surface?url=…・MCP surface_inspect

参考にした考え方: morluto/rea（ローカルのアプリやバイナリを解析して機能を理解する MCP ツール）。ここでは対象を「公開されている Web/API の表面」に限定し、認証回避・課金回避は実装していません。
限界: SPA の描画後DOMは取れない／認証後の内部APIは見えない／エンドポイントは文字列としての出現で動作確認はしていない。
